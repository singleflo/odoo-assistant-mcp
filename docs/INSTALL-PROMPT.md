# The one-paste install prompt

Copy the block in your language and paste it, as a single message, into the
AI assistant you use on your computer — Hermes, Claude Code, Claude Desktop,
Codex, Cursor, opencode or similar. The assistant installs Singleflo for Odoo
by itself, walks you through creating the Odoo API key one click at a time,
and checks that the connection works. You need nothing else at hand: just your
Odoo open in the browser.

Using Claude.ai or ChatGPT in the browser? The same prompt works there too —
the assistant notices it cannot install anything and guides you through the
hosted connection instead.

The full instructions the assistant follows are in
[INSTALL-WITH-YOUR-AGENT.md](INSTALL-WITH-YOUR-AGENT.md).

## English

```text
Please install "Singleflo for Odoo" (the MCP server `odoo-assistant`) so that you can work with my Odoo.
Open and follow, step by step, the instructions written for you at:
https://raw.githubusercontent.com/singleflo/odoo-assistant-mcp/main/docs/INSTALL-WITH-YOUR-AGENT.md
I am not technical. Talk to me in English, give me one simple step at a time and wait for my answer, and do all the technical work yourself.
When you need the Odoo API key, guide me through creating it screen by screen. Never ask me for my Odoo password.
At the end, check that you can read my Odoo and tell me what you set up.
```
